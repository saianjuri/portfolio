# Dr. Mettu Portfolio

Build a premium, clean, human-designed personal portfolio website for a PharmD professional named “Dr. Mettu”.

IMPORTANT DESIGN GOAL:
The website must NOT look AI-generated, template-generated, or overly futuristic. It should feel like a professionally designed personal portfolio created by an experienced human UI/UX designer.

Use the attached reference image as the PRIMARY visual design reference. Closely follow its overall composition, spacing, typography hierarchy, card structure, color language, and visual balance, but do not make it an obvious pixel-for-pixel copy.

DESIGN STYLE:
- Premium personal portfolio
- Medical + fitness + nutrition + creative photography personality
- Clean editorial design
- Minimal and elegant
- Lots of whitespace
- Strong typography
- Subtle shadows
- Soft rounded corners
- Very restrained animations
- No glassmorphism
- No excessive gradients
- No 3D objects
- No generic AI illustrations
- No unnecessary decorative elements
- No excessive animations
- No huge glowing effects
- No “AI startup” aesthetic

COLOR PALETTE:
Use the reference image's color palette consistently.

Primary Teal: #16A6A8
Accent Orange: #F36A32
Warm Cream / Ivory Background: #FAF8F3
Dark Text: #171A1D
White: #FFFFFF

Teal should represent the professional/medical identity.
Orange should be used as a secondary accent for energy, fitness, photography and important CTAs.
Do not introduce additional major colors.

TYPOGRAPHY:
Use a modern professional sans-serif font such as Inter, Manrope, or a similarly polished humanist sans-serif.
Strong typography hierarchy.
Headings should be bold but not oversized.
Body text should be highly readable.
Avoid trendy experimental fonts.

RESPONSIVE DESIGN:

Desktop:
- Spacious two-column hero
- Four-column pillar cards
- Strong visual hierarchy

Tablet:
- Adjust grid naturally
- Maintain whitespace

Mobile:
- Stack hero vertically
- Portrait below or above content depending on visual balance
- Two-column or single-column credibility cards
- Single-column pillar cards
- Clean mobile navigation menu
- Large touch-friendly CTA buttons
- No horizontal scrolling

ANIMATIONS:

Use ONLY subtle animations:
- Fade/slide-up on section entrance
- Very subtle hover elevation on cards
- Button hover transitions
- Smooth scrolling

Do NOT animate everything.
Do NOT use excessive parallax.
Do NOT use bouncing elements.
Do NOT use flashy transitions.

CODE QUALITY:

- Build reusable React components.
- Use clean component architecture.
- Use Tailwind CSS or the existing Lovable styling system.
- Keep spacing and typography consistent.
- Use semantic HTML.
- Make the website accessible.
- Optimize images.
- Make the site fast and responsive.
- Add proper hover/focus states.
- Ensure all buttons and navigation links work.
- Use clean URLs/anchors for sections.

MOST IMPORTANT:
The final result should look like a premium, real-world personal portfolio website designed specifically for Dr. Mettu — NOT like an AI-generated landing page.

Prioritize:
1. Visual cleanliness
2. Typography
3. Spacing
4. Real photography
5. Consistent teal + orange color system
6. Professional medical credibility
7. Personal-brand feel
8. Human-designed appearance

Do not add sections that are not requested unless they genuinely improve the portfolio.
Do not invent qualifications, awards, hospitals, certifications, patient numbers, testimonials, or professional claims.
Use placeholders where information is not yet provided.

## Development

Requires Node.js and npm (or bun).

```sh
npm install
npm run dev
```

Build:

```sh
npm run build
npm run preview
```

Stack: TanStack Start (React 19) + Vite + Tailwind CSS v4.
